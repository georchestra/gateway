# User guide

The gateway is mostly invisible to the users of a geOrchestra platform: it sits in front of every
application and only shows up when you **sign in**, **sign out**, or when something goes wrong
(error pages).

This guide describes what a user can see and do with the gateway:

- [Signing in and out](login.md): the login page, the available login methods, logout,
  and the messages you may get.
- [Gateway endpoints](endpoints.md): the few URLs served by the gateway itself (`/login`, `/logout`,
  `/whoami`, ...), useful to understand or debug your session.

!!! note
    The exact look of the login page, the available login methods and the URLs of the applications
    depend on how your platform has been configured by its administrators. Screens may differ
    from the default ones described here.
